# services/ai-worker — runs NATIVELY on macOS-arm64, not in Docker.
#
# Why native: paddlepaddle's linux/arm64 wheel story is far weaker than its
# macOS-arm64 story, and x86 emulation makes OCR too slow for a live demo.
# See docs/architecture.md "Runtime topology".
#
# Install into a python3.12 venv:
#   /opt/homebrew/bin/python3.12 -m venv .venv
#   .venv/bin/pip install -r requirements-ai.txt
#
# IMPORTANT — Devanagari rendering prerequisite:
#   Pillow must be linked against libraqm or Devanagari shaping is wrong and
#   the synthetic dataset's ground truth will not match its images.
#     brew install libraqm
#     PKG_CONFIG_PATH=/opt/homebrew/lib/pkgconfig \
#       pip install --force-reinstall --no-binary :all: --no-cache-dir Pillow
#   Guarded by tests/ai/test_devanagari_stack.py
